# Project Constitution v1.0

## 목적

Project PlayAds는 AI를 활용하여 브라우저 기반 인터랙티브 콘텐츠를 반복적으로 생산할 수 있는 개발 시스템을 구축하는 것을 목표로 한다.

본 프로젝트는 단일 게임 제작이 아니라, 지속적으로 게임과 웹 도구를 제작할 수 있는 플랫폼 구축을 지향한다.

---

# 제1조 프로젝트 목표

프로젝트의 최우선 목표는 다음 순서를 따른다.

1. 광고 수익
2. 검색 유입
3. 사용자 만족
4. 재방문
5. 콘텐츠 생산성

---

# 제2조 적용 범위

본 프로젝트는 다음 콘텐츠에 적용한다.

- HTML5 게임
- 계산기
- 테스트
- 생성기
- AI 기반 인터랙티브 콘텐츠

기존 hooind.com의 일반 콘텐츠(이슈, 경제, 영화 등)는 적용 대상이 아니다.

---

# 제3조 기술 원칙

기본 기술

- HTML5
- CSS
- Vanilla JavaScript
- Canvas API
- LocalStorage

필요하지 않은 경우 React, Vue 등 프레임워크는 사용하지 않는다.

---

# 제4조 개발 원칙

모든 콘텐츠는 Template 기반으로 개발한다.

복사 후 수정 가능한 구조를 기본으로 한다.

공통 기능은 shared 모듈을 우선 사용한다.

---

# 제5조 WordPress 원칙

모든 콘텐츠는 WordPress에 쉽게 삽입 가능해야 한다.

특정 서버 환경에 종속되는 구조를 만들지 않는다.

---

# 제6조 모바일 우선

모든 화면은 Mobile First로 설계한다.

Desktop은 Mobile의 확장판으로 개발한다.

---

# 제7조 성능

첫 화면은 가능한 빠르게 렌더링한다.

불필요한 라이브러리 사용을 금지한다.

Console Error 0건을 목표로 한다.

---

# 제8조 사용자 경험

사용자는 설명서를 읽지 않아도 사용할 수 있어야 한다.

게임은 5초 안에 시작할 수 있어야 한다.

계산기는 입력 후 즉시 결과를 보여준다.

---

# 제9조 SEO

검색 유입을 고려하여 URL, 제목, 설명을 작성한다.

콘텐츠는 검색 의도를 충족해야 한다.

---

# 제10조 광고

광고는 콘텐츠를 방해하지 않는다.

광고 위치는 표준 템플릿을 따른다.

광고 때문에 CLS가 발생하지 않도록 한다.

---

# 제11조 데이터 저장

브라우저 저장은 LocalStorage를 기본으로 한다.

개인정보는 저장하지 않는다.

---

# 제12조 AI 개발 원칙

GPT

- PM
- 설계
- 문서

Codex

- 개발

Claude Code

- 코드 리뷰

Claude

- 콘텐츠 작성
- WordPress 발행

---

# 제13조 버전 관리

모든 변경사항은 CHANGELOG에 기록한다.

주요 정책 변경은 Constitution을 우선 수정한다.

---

# 제14조 최우선 원칙

코드는 한 번 작성하고 여러 콘텐츠에서 재사용할 수 있어야 한다.

중복보다 재사용을 우선한다.

# 제15조 콘텐츠 생산 원칙

모든 콘텐츠는 다음 조건을 만족해야 한다.

- 템플릿 기반으로 제작 가능해야 한다.
- AI가 수정하기 쉬워야 한다.
- 사람이 이해하기 쉬워야 한다.
- SEO에 적합해야 한다.
- 광고를 삽입할 수 있어야 한다.
- 모바일에서 정상 동작해야 한다.
