# Hooind Brand Identity v0.1

## 1. 문서 목적

이 문서는 hooind.com 전체 사이트의 운영 규정이 아니라, 게임·계산기·테스트·생성기 등 신규 인터랙티브 콘텐츠 영역의 제작 및 운영 기준을 정의한다.

기존에 운영 중인 이슈, 경제, 영화 등의 정보성 콘텐츠는 기존 방식으로 계속 운영하며 본 프로젝트의 적용 범위에서 제외한다.

---

## 2. 브랜드 및 프로젝트 구조

### 상위 사이트·브랜드

**Hooind**

공식 도메인: **hooind.com**

Hooind는 이슈, 경제, 영화 등 기존 정보성 콘텐츠와 신규 인터랙티브 콘텐츠를 함께 제공하는 웹사이트다.

### 신규 콘텐츠 영역

**Hooind Interactive**

게임, 계산기, 테스트, 생성기 등 사용자가 직접 실행하고 참여하는 콘텐츠 영역을 의미한다.

### 내부 프로젝트 코드명

**Project PlayAds**

AI를 활용해 인터랙티브 콘텐츠를 기획, 개발, 검토, 배포하는 생산 체계를 구축하는 내부 프로젝트명이다.

### 제작 주체 표기

**Hooind Studio**

신규 게임과 웹 도구의 제작 조직 또는 크레딧 명칭으로 사용한다.

예시:

- Created by Hooind Studio
- A Hooind Studio Project

---

## 3. 프로젝트 비전

> 누구나 설치 없이 바로 사용할 수 있는 재미있고 유용한 웹 콘텐츠를 만든다.

Hooind Interactive의 콘텐츠는 별도 프로그램 설치나 회원가입 없이 브라우저에서 바로 실행할 수 있어야 한다.

게임은 재미를 제공하고, 계산기와 도구는 문제를 해결하며, 테스트와 생성기는 사용자의 참여와 공유를 유도한다.

---

## 4. 프로젝트 핵심 가치

### 간단함

사용자는 긴 설명 없이도 콘텐츠를 사용할 수 있어야 한다.

### 즉시성

페이지에 접속하면 바로 실행하거나 결과를 확인할 수 있어야 한다.

### 유용함

단순한 페이지뷰보다 실제 사용 목적이 있는 콘텐츠를 우선한다.

### 재미

계산기나 도구형 콘텐츠도 지루하지 않은 사용자 경험을 제공한다.

### 반복 사용

한 번만 방문하는 콘텐츠보다 다시 사용할 가능성이 있는 콘텐츠를 우선한다.

### 확장성

게임에 한정하지 않고 계산기, 테스트, 생성기와 AI 콘텐츠로 확장할 수 있어야 한다.

## 5. 프로젝트 적용 범위

### 적용 대상

- HTML5 브라우저 게임
- 계산기
- 테스트
- 랜덤 생성기
- 생활형 웹 도구
- 향후 AI 기반 인터랙티브 콘텐츠

### 적용 제외

- 기존 이슈 콘텐츠
- 기존 경제 콘텐츠
- 기존 영화 콘텐츠
- 기존 블로그 작성 및 발행 방식
- 현재 WordPress 사이트의 전면 개편

기존 콘텐츠는 기존 운영 방식을 유지한다.

- 날짜 계산기

향후 제공할 AI 기반 기능

예시:

## 7. 네이밍 규칙

서비스 범주는 다음 규칙을 따른다.

`Hooind + 콘텐츠 범주`

예시:

- Hooind Games
- Hooind Tools
- Hooind Tests
- Hooind Makers
- Hooind AI

개별 콘텐츠 제목에는 Hooind를 반복해서 붙이지 않는다.

권장 예시:

- 반응속도 테스트

- 퇴직금 계산기
- 2048 게임

제작 브랜드는 하단 또는 소개 영역에 다음과 같이 표시할 수 있다.

`by Hooind`

## 8. URL 구조

기본적으로 hooind.com 아래에 콘텐츠 유형별 경로를 구성한다.

```text
hooind.com/games/
hooind.com/tools/
hooind.com/tests/
hooind.com/makers/
hooind.com/ai/
```

개별 콘텐츠 예시:

```text
hooind.com/games/reaction-speed/
hooind.com/games/memory-game/
hooind.com/tools/severance-pay-calculator/
hooind.com/tools/salary-calculator/
hooind.com/tests/reaction-time/
hooind.com/makers/lotto-number-generator/
```

실제 WordPress의 기존 카테고리 및 고유주소 구조와 충돌하는 경우 배포 단계에서 조정한다.

## 9. 기술 방향

### 기본 기술

- HTML5
- CSS
- Vanilla JavaScript
- Canvas API
- LocalStorage
- WordPress

### 사용하지 않는 기술

특별한 필요가 없는 한 다음 기술은 사용하지 않는다.

- React
- Vue
- Angular
- Unity
- Electron
- 불필요한 Node.js 기반 구조

### 기본 원칙

- 모바일 우선
- 설치 없이 실행
- 서버 기능 최소화
- 불필요한 외부 라이브러리 사용 금지
- 공통 기능 재사용
- WordPress 삽입이 쉬운 구조

## 10. 공통 기능

초기 인터랙티브 콘텐츠 템플릿은 필요한 경우 다음 기능을 공통으로 제공한다.

- 시작
- 일시정지
- 재시작
- 점수 표시
- 최고 점수 저장
- 사운드 설정
- 결과 또는 게임 종료 팝업
- 모바일 터치 지원
- 키보드 지원
- 광고 슬롯
- 관련 콘텐츠 이동

콘텐츠 특성상 필요하지 않은 기능은 제외할 수 있다.

---

## 11. 데이터 저장 규칙

브라우저 내부 저장이 필요한 경우 LocalStorage를 기본으로 사용한다.

키 형식:

```text
hooind.{contentType}.{contentId}.{dataName}
```

예시:

```text
hooind.games.reaction.bestScore
hooind.games.snake.soundEnabled
hooind.tests.memory.bestTime
hooind.tools.salary.lastInput
```

민감정보와 개인정보는 LocalStorage에 저장하지 않는다.

- 가볍고 현대적일 것
- 친근하지만 지나치게 유아적이지 않을 것

- 명확한 대비
- 짧은 안내 문구
- 직관적인 아이콘
- 불필요한 장식 최소화
- 기존 WordPress 디자인과 가능한 범위에서 조화

기존 Hooind 사이트의 헤더, 메뉴, 사이드바, 푸터는 현재 운영 방식을 유지한다.

## 16. SEO 방향

브랜드 검색보다 개별 콘텐츠 키워드를 통한 유입을 우선한다.

예시:

- 반응속도 테스트
- 로또 번호 생성기
- 퇴직금 계산기
- 무료 2048 게임
- 기억력 테스트

기본 사용자 흐름:

```text
검색 키워드
↓
개별 콘텐츠 방문
↓
콘텐츠 사용
↓
관련 콘텐츠 이동
↓
Hooind 브랜드 인지
```

신규 콘텐츠의 SEO 원칙은 기존 이슈, 경제, 영화 콘텐츠의 작성 규칙과 별도로 관리한다.

---

## 17. 광고 원칙

광고 수익은 프로젝트의 핵심 목표이지만 콘텐츠 이용을 방해하지 않아야 한다.

### 기본 원칙

- 콘텐츠 시작 버튼과 광고를 지나치게 가깝게 배치하지 않는다.
- 게임이나 도구의 실행 화면을 광고가 가리지 않도록 한다.
- 사용자의 실수 클릭을 유도하지 않는다.
- 광고 로딩으로 화면이 이동하지 않도록 공간을 확보한다.
- 모바일 화면을 우선하여 광고 위치를 결정한다.
- 광고 위치를 공통 템플릿으로 관리한다.
- 초기 개발 단계에서는 광고 코드보다 광고 슬롯을 먼저 정의한다.

## 18. 성공 기준

프로젝트의 성공 우선순위는 다음과 같다.

```text
광고 수익
↓
검색 방문자
↓
재방문
↓
페이지뷰
↓
체류시간
↓
콘텐츠 개수
```

많은 콘텐츠를 만드는 것보다 실제 사용자가 방문하고 반복 이용하는 콘텐츠를 만드는 것이 중요하다.
