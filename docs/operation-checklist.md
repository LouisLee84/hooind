# Hooind 운영 체크리스트

## 배포 전

- [ ] `main`이 원격 저장소와 동기화되어 있다.
- [ ] 작업트리가 깨끗하다.
- [ ] GitHub Actions가 통과했다.
- [ ] `pnpm format:check`, `lint`, `typecheck`, `test`, `test:e2e`, `build`가 통과했다.
- [ ] Production 환경변수에 실제 운영값이 등록되어 있다.
- [ ] `NEXT_PUBLIC_SITE_URL`이 대표 도메인과 일치한다.
- [ ] 개인정보처리방침, 이용약관·면책, 문의 페이지 내용을 검토했다.
- [ ] 공개 문의 이메일을 설정했다.
- [ ] 계산 공식 또는 기준 변경이 CHANGELOG에 기록되었다.

## 배포 직후

- [ ] 홈, 계산기 목록과 계산기 3종이 정상 응답한다.
- [ ] 개인정보처리방침, 이용약관·면책, 문의 페이지가 열린다.
- [ ] Footer의 운영 링크가 정상 동작한다.
- [ ] 존재하지 않는 경로가 404 상태와 사용자 정의 화면을 반환한다.
- [ ] 오류 화면에 민감한 세부정보가 노출되지 않는다.
- [ ] `/sitemap.xml`이 절대 운영 URL을 반환한다.
- [ ] `/robots.txt`가 운영 sitemap 주소를 포함한다.
- [ ] 홈과 모든 공개 페이지의 canonical이 대표 도메인을 사용한다.
- [ ] OpenGraph와 Twitter 메타데이터를 확인했다.
- [ ] WebApplication·FAQPage 구조화 데이터를 검사했다.
- [ ] 390px 모바일 화면에서 가로 넘침이 없다.
- [ ] Lighthouse 모바일 검사를 실행하고 주요 저하 원인을 기록했다.

## 검색엔진

- [ ] Google Search Console에 Domain 또는 URL-prefix 속성을 등록했다.
- [ ] HTML 메타 태그 방식을 사용할 경우 `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`을 설정했다.
- [ ] Search Console에서 소유권 인증을 완료했다.
- [ ] `https://hooind.com/sitemap.xml`을 제출했다.
- [ ] robots 테스트에서 공개 페이지가 차단되지 않는지 확인했다.
- [ ] 대표 URL과 www 리디렉션 정책이 일치한다.

## 분석과 광고

- [ ] GA4 Measurement ID를 Production에만 등록했다.
- [ ] GA4 Realtime에서 실제 방문과 기본 page_view 수집을 확인했다.
- [ ] 내부 테스트 트래픽 제외 필요성을 검토했다.
- [ ] AdSense 클라이언트 ID를 등록하기 전 계정과 사이트 승인을 확인했다.
- [ ] AdSense 스크립트가 한 번만 로드되는지 확인했다.
- [ ] 광고 슬롯 도입 전 기존 고정 높이와 CLS를 확인했다.
- [ ] 개인정보처리방침이 실제 활성화된 분석·광고 방식과 일치한다.

## 주요 기능

- [ ] 퇴직금 계산기의 정상·오류 입력을 확인했다.
- [ ] 연봉 실수령액 계산기의 정상·오류 입력을 확인했다.
- [ ] 주휴수당 계산기의 정상·미대상 입력을 확인했다.
- [ ] 홈과 계산기 목록에서 계산기 3종으로 이동할 수 있다.
- [ ] 브라우저 콘솔 오류가 없다.

## 모니터링과 롤백 기준

다음 중 하나가 발생하면 신규 배포 중단 또는 롤백을 검토합니다.

- 주요 경로의 지속적인 5xx 응답
- 계산 결과를 사용할 수 없는 JavaScript 오류
- 이전 계산 결과와 의도하지 않은 차이
- canonical 또는 robots 오류로 운영 페이지가 잘못 차단됨
- 심각한 모바일 레이아웃 붕괴
- 개인정보 또는 비밀값 노출
- GA4·AdSense 스크립트의 반복 오류로 사용자 경험 저하

롤백 후 마지막 정상 배포의 주요 경로와 계산 흐름을 다시 확인하고, 수정 배포는 Preview에서 검증한 뒤 Production으로 승격합니다.
